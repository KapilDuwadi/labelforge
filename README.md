# LabelForge

**Design product labels and generate print-ready PDFs — right in your browser.**

🔗 **[Open LabelForge](https://kapilduwadi.github.io/labelforge/)**

---

## What it does

LabelForge lets you create reusable label templates for physical products and export them as a print-ready PDF. Cut along the dotted lines and stick them on your products.

Each label includes:
- **Product Name**
- **Description**
- **Ingredients**
- **Process** (how it's made)
- **Country of Origin**
- **Net Weight**

Set a **print count** per template to control how many copies appear in the PDF.

## Features

- Create, edit, and delete label templates
- Live label preview as you type
- Generate a PDF with all labels arranged in a 2-column grid (6 per page)
- Dotted cut guides on every label
- Supports **Letter** (US) and **A4** paper sizes
- Templates saved locally in your browser — no account needed
- Works on desktop and mobile
- No install, no backend — runs entirely in the browser

## Usage

1. Click **+ New Label** to create a template
2. Fill in the product details
3. Set the **Print Count** (how many copies you need)
4. Click **Save Changes**
5. Repeat for each product
6. Click **↓ PDF** to download your print sheet

## Tech

Pure HTML + CSS (Tailwind CDN) + JavaScript. No build step, no dependencies to install.
